# Third-party notices

This repository does not vendor CEF or HaxBall code.

At build time, the Windows application can download the official Chromium Embedded Framework binary distribution from the CEF automated build service. CEF/Chromium are distributed under their respective licenses; consult the downloaded distribution's license files.

HaxBall is a separate product. This project is unofficial and loads the public official HaxBall website without bundling HaxBall source code or assets.

PresentMon is not bundled. The optional calibration script can invoke a separately installed PresentMon executable.
